# Joy2key by kmpfmffn

<p>
Joy2key application that <b>simulates keyboard and mouse input</b> from <b>gamepad input</b>.
Proven working on <b>Kubuntu 25.10</b>. Propably works on other versions as well.
</p><p>
Note: For now it's <b>hard coded</b> for my <b>personal use</b>. Configurability will follow in later versions.
</p>

## Compilation

Either build using CMake or compile using
> g++ -o joy2key joy2key.cpp

## Available keybinds

- Mouse movement
- Mouse scrolling
- Mouse buttons (left, middle, right)
- Space bar
- Media buttons (volume+/-, play/pause, next song, previous song)
- Alt-Tab window switching menu
